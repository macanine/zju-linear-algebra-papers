# solutions/ —— 解析体

与 `papers/` **同名一一对应**，一纸一份：`<学年>-<学期>-<考试>-<课程>.tex`。
这里**只写解析**，不抄题干、不写题号、不写 `\documentclass`／`\paperhead`——题目原文以 `papers/` 为唯一来源，
构建时由 `tools/build.py` 按题序把解析插到对应题目之后。

## 文件形状

```latex
% =====================================================================
%  整理者　macanine <macanine@163.com>
%  仓库　　github.com/macanine/zju-linear-algebra-papers
%  来源　　解析据 papers/2019-2020-秋冬-期中-甲.tex 撰写（原卷见 sources/2016-2025-期中-甲-历年真题汇编.pdf 第 7 页）
% =====================================================================

\begin{solution}
第 1 题的推导……
\ans{第 1 题的结论}
\end{solution}

\begin{solution}
第 2 题……
\end{solution}
```

- 块数必须等于该卷 `\begin{problem}` 的个数，顺序即题序；不匹配 `build.py` 直接报错。
- 自查：`python3 tools/build.py --check`。
- `\begin{solution}` 渲染成粗体「解」，所以块内**不要**再写“解”字。

## 三个可用的宏

| 宏 | 用途 |
| --- | --- |
| `\begin{solution} … \end{solution}` | 每题一个，必写 |
| `\ans{…}` | 结论行，渲染成「答案　…」。**凡题目要求具体结果**（数值、行列式、矩阵、通解、秩、过渡矩阵、坐标、多项式等）的，解析末尾必须用它给出；纯证明题不用 |
| `\rem{…}` | 评注，点明关键思想或常见错处。**每卷不超过 3 处**，没有就不写 |

小问用 `\begin{enumerate}[label=(\arabic*),leftmargin=2.2em,itemsep=0.25em,topsep=0.3em]`，
编号与题干的小问 `(1)(2)` 对应。

## 写作要求

**完备且简要。** 目标是让读者看懂“为什么这么做”，而不是看一堆算式。因此：

- 关键一步要**说方法的名字**（如“按第一列展开得递推式”“用行倍加把第 1 行消成零”“由秩－零化度定理”“构造 $P$ 使 $AP$ 为 Hermite 标准形”），
  纯计算题的机械化简可以合并成一步写“初等行变换化为行最简形”。
- 论证链不能跳。证明题引用的定理要指明（如“$r(AB)\le\min\{r(A),r(B)\}$”“伴随矩阵秩的结论”），
  不能只写“显然”“易知”堆过去。
- 该交代的分情形要交代全（参数取何值、是否退化、$n$ 的奇偶、分母是否为零），
  题干里“无解／唯一解／无穷多解”这类问题必须逐项回答。
- 计算题可以给一个**验算招**（代入回代、特例取 $n=1,2$），但不啰嗦。

**忠实题干记号。** 题干用 `A'` 就别改写成 `A^{T}`，用 `E` 就别换成 `I`，用 `\theta` 表示零向量就沿用。
解析里出现的符号必须与题干一致，否则读者对不上。

## LaTeX 硬约束

- 不用 `$$`；行内 `$...$`，独立公式 `\[...\]`。
- 矩阵用 `pmatrix`／`bmatrix`／`vmatrix`；分段用 `cases`；对齐用 `align*`（**不要带编号**）。
- 分数用 `\dfrac`（行内分数避免挤在一起）。
- 禁止出现 `Overfull \hbox`：矩阵列多时在环境内加 `\setlength{\arraycolsep}{4.5pt}`，
  超长等式用 `align*` 拆行，或把中间矩阵单独提行。
- 年份写 `2024--2025`（en dash）；百分号、下划线记得转义（`\%`、`\_`）。
- 中文与公式之间该有的标点照常写；句末“为 $1$。”这类行尾孤字用 `\mbox{~$1$}` 保一下。

## 质量流程

写完一卷：`tools/build.py --check` 过 → 出解析版审阅（`python3 tools/build.py book-甲-期中-秋冬-解析.yaml`）
→ 逐页看渲染结果（无裁切、无重叠、公式不断行、留白合理）→ 与 `papers/` 的题干逐题对照，确认没有答非所问。
